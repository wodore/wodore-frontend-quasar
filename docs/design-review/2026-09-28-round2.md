# Design Review — Round 2 (2026-09-28)

Captured with live staging data (backend recovered: hut detail, pin
geojsons, search all 200). Screenshots in `/tmp/r2-*`. Five fresh-context
vision critiques; findings below are filtered against owner decisions.

## Shipped in this round (verified on deployed previews)

- **Date stepper** = one segmented control (single dashed frame, internal
  dividers @0.34 alpha) — computed + vision verified.
- **Menu drawer**: shadow-2 → tonal ridge edge (Tonal Layer Rule).
- **Filter badge** on the overlay rail: 8px turquoise dot + chip ring
  (selected-state semantics).
- **Hut title voice**: desktop 400 / mobile 500 → both 500 (spec Title).
- **Review-status badge** ("ungeprüft" etc.): bare floating text with
  shadow → tonal pill (ridge border, no shadow, uppercase micro-label).
- **Night weather text floor**: precip/min-temp were ~2.5:1 on pine →
  0.7 alpha floor (won the scoped-CSS cascade with an extra class hop).

## Round-2 findings (open)

### Search (results state — finally captured)

1. **[med] Empty-below-results**: card stays tall with blank space under
   the last row — cap height to content.
2. **[med] Row hierarchy flat**: name vs meta (type/region) read at equal
   weight — meta smaller + muted; add row hover affordance.
3. **[low] Card/input seam**: fully rounded card corners vs rectangular
   input above read detached — align radii/padding (8px card ramp).

### Hut body (night)

4. **[med] Weather tiles read "sunken"**: the today fill on pine can read
   darker than surroundings; considered gold ring → gold left-tick (2
   critics preferred) — kept the ring (owner-approved unified language);
   revisit if it still reads sunken in person.
5. **[low] Precip micro-typography**: "◇ 2.0mm" mixes icon/numeral/unit —
   consider "2 mm" (drop decimals), one size up.

### Mobile map rail (from the search-mobile capture)

6. **[high] Rail circles below 44px touch minimum** — S3 item (collapse
   to chip / 40px circles + gaps); needs mockup + owner call.
7. **[low] Rail buttons merge with light map ink** — grouped single
   panel + one shared shadow (allowed: floating over imagery).

### Scrolled drawer header

8. **[med] Scrolled-state separation too subtle** — ridge + tint exists
   but reads invisible in Day; strengthen (1px ridge bottom + paper tint
   sooner).
