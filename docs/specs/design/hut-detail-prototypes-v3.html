Wodore Hut Detail - Design Variations v3

4 design approaches based on wd_place_details_variations.md

Changes from v2:

  • Monthly gradient colors from months.scss
  • Detailed category symbols (inline SVGs)
  • Category names from API (Hütte, Winterraum, etc.)
  • Availability: Next 4 days with weather & beds
  • Snap 3 with full details (weather, location, reviews)
  • Status badges per category (✓ / ✗ / ?)
  • 4 snap positions (0=dismiss, 1=header, 2=main, 3=full)
  • Shared snap heights across all variations
  • Action toolbar with source buttons (SAC, OSM, HRS)
  • Description with attribution
  • Book button variations
  • Stand-alone (no localhost dependencies)
