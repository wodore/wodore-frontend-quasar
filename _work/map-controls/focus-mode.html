Focus mode · Notes
  • + 100% map; perfect for reading terrain, screenshots, showing friends.
  • + Single exit button (forest green, 52 px) — unreachable-by-accident but easy to hit deliberately.
  • − Hides pins' context briefly; first-time users may feel lost — the bottom-left hint pill fades after 3 s.
  • − Tapping a map PIN must NOT trigger focus mode — only empty map does.
