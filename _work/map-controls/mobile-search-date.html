Map Controls Proposal · 2026-10 · MobileMobile Chrome Without a Toolbar — split search + date bar, menu placement, Day & Night

Mobile drops the app toolbar entirely. A large floating bar at the top carries the two things that drive the map: what/where to search and when — the date drives availability, so it shows the selected date plus a small availability state dot. The date value uses the amber ramp for its state dot (data, not brand gold). Menu / profile / theme move into a small menu button (top-right). All variants in Day and Night.

Variant A · Pros / Cons
  • + One object, one shadow — cleanest over-map reading; search and date read as one instrument panel.
  • + 60/40 split: search keeps room for long queries; date segment carries weekday, date AND availability summary (green = free beds on that date).
  • + Ridge hairline (never shadow) separates the segments; each opens its own sheet (search vs. date picker).
  • − Very long place names crowd the 60% segment (ellipsis, as mocked).
  • − Availability dot needs a tooltip/sub-label to never speak by color alone — solved with the "Free beds" text.

Variant B · Pros / Cons
  • + Search gets full width minus menu; roomiest for long queries and recents.
