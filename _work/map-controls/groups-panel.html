Map Controls Proposal · 2026-10 · MobileLayer Groups & Panel — bottom-right stack, three panel variants, Day & Night

Mobile only, no app toolbar. All floating controls move to the bottom-right, stacked above the basemap fab; the panel opens bottom-to-top. Layer groups are user-defined; one group is active at a time. Short press on the group fab cycles Winter → Summer → All-huts → …; long press opens the full group picker. The panel shows only the active group's layers plus a "More" button (other layers, settings, group management). Sizes: 48–56 px touch targets. Barlow Semi Condensed uppercase labels (system sans stand-in here). Map stays a light basemap in both themes.

Variant A · Pros / Cons
  • + Every layer gets a name, meta line and dedicated info + filter buttons — most explicit per-layer access.
  • + 44 px mini buttons meet target size; scannable hierarchy.
  • − Tallest panel of the three; with 4+ layers it eats the lower map half.
  • − Toggle + two buttons per row = 3 targets per layer, visually busy.

Variant B · Pros / Cons
  • + Chip tap toggles the layer in one hit; the small handle (≥26 px, expandable to 44 px hit area) is the only path to info/filter — clean separation of on/off vs. learn/configure.
  • + Tray appears only on demand; compact panel keeps most of the map visible; scales to many layers via wrapping.
  • + Active layer = forest-green fill with inset gold beam ring — token-conform.
  • − Two-tier gesture on a chip (tap vs. handle) needs a clear affordance + 44 px hit slop on the handle.
  • − No per-layer meta visible at rest (counts only).

Variant C · Pros / Cons
  • + Smallest panel; pure on/off layer switching; nothing competes with the map.
  • + One More button collects info, filters, settings — fewest decisions per glance.
  • − Info/filter for a layer costs 3+ taps (More → pick layer → filter) — weak per-layer access.
  • − Power users (check slope hazards details often) will find it slow.

Variant D — Expandable panel with minimized icon strip (the mix)

Owner proposal: open the full menu for names, trays and More — then minimize to an icon-only strip that keeps the one-tap-per-layer toggling of today's rail. The strip shows only the active group's layers (stacked above the group fab, above the basemap fab), stays open while you work the map, and long-press on any strip icon still slides out the info/filter tray.
